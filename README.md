# 🎰 拉霸機 — Slot Machine

> Cocos Creator 3.8.8 作品集專案 · 全程式生成 UI，無外部美術資源

## ✨ 功能

| 功能 | 說明 |
|------|------|
| 🎡 **真實轉輪滾動** | 每輪用 `Mask` 裁切 + 垂直 strip + `tween` cubicOut 減速，三輪錯開停止（1.0 / 1.35 / 1.7s） |
| 💰 **押注分級** | 10 / 20 / 50 / 100，`＋ −` 按鈕切換，旋轉中自動禁用 |
| 🔢 **分數滾動動畫** | 中獎時分數從舊值平滑遞增到新值 |
| 💥 **中獎特效** | 中獎符號 scale 脈動 + 變色閃爍 |
| 🏆 **BIG WIN 彈窗** | JACKPOT / 三連線時彈出全螢幕特效（backOut 縮放 + 淡入淡出） |
| 🔁 **自動旋轉** | AUTO 按鈕切換連續旋轉，餘額不足自動停 |

## 🎲 賠率

| 結果 | 賠率 |
|------|------|
| 777 三連線（JACKPOT） | 押注 × 50 |
| 其他符號三連線 | 押注 × 10 |
| 任意兩連線 | 押注 × 3 |

符號：`7 ★ ◆ ♣ ♥ BAR`

## 🛠 技術

- **引擎**：Cocos Creator 3.8.8 + TypeScript
- **UI**：全程式生成（`Graphics` 繪製圓角矩形 / 邊框 / 城市夜景 / 燈泡），零美術資源
- **動畫**：`tween` 系統（位移、縮放、透明度、緩動函式）
- **遮罩**：`Mask` GRAPHICS_RECT 實現轉輪視窗裁切
- **架構**：單一 `SlotMachine.ts` 組件；`_box()` / `_brd()` / `_lbl()` / `_button()` 可重用繪圖原語

## ▶ 執行

1. 以 Cocos Creator 3.8.8 開啟本資料夾
2. 開啟 `assets/scene.scene`
3. 按 ▶ Play 預覽（設計解析度 1280×720）
